把 DLNA、AirPlay 与妙播编织成一条本地声音路径。无需云端账号，也无需更换家中支持 DLNA 的音响。

完全运行在局域网 标准声路无需账号 Docker 快速部署

一眼看懂全屋声路

最多展开三条活跃路径，其余聚合，不让音响数量破坏首页。

每台音响独立管理

启停只影响当前音响的 Receiver Suite，不存在全局默认输出。

成功必须真的拉到声音

实体音响没有拉取 HTTP 音频时，不把控制命令成功冒充播放成功。

HOW IT WORKS · 三步接通

协议很复杂，
使用不应该复杂。

01

发现局域网音响

扫描标准 UPnP/DLNA MediaRenderer，不要求先登录小米或其他厂商账号。

SSDP → device description → services
02

发布独立接收入口

每台已启用音响获得自己的 DLNA、AirPlay 和妙播名称，多个房间可以同时存在。

Receiver Suite × output speaker
03

把声音送到实体输出

CastFabric 不止发送控制命令，还确认实体 DMR 真正打开并拉取音频流。

SOAP Play → HTTP GET → verified output

SELF-HOST IN MINUTES

让 Home Server
接住家里的声音。

推荐 Linux host network，以便 SSDP 和 mDNS 在局域网正常工作。配置保存在本地目录，更新容器不会删除音响设置。
